# Рабочая область ESP32

Здесь находятся прикладные проекты прошивок ESP32.

SDK ESP-IDF расположен отдельно: `../esp-idf`.
Примеры Espressif находятся в `../esp-idf/examples` и не изменяются без отдельной необходимости.

## Рабочий порядок

1. Открывать в VS Code отдельный каталог прикладного проекта.
2. Выбирать target через `ESP-IDF: Set Espressif Device Target`.
3. Сначала выполнять сборку (`Build`).
4. Прошивку и подключение платы выполнять только после проверки модели платы, распиновки и порта.
