# ESP32

Рабочий проект ESP32 на ESP-IDF 6.0.2. Основная прошивка — стабильный тест
мигания светодиодом. Дополнительные эксперименты хранятся отдельно в `examples`.

## Структура

```text
/home/work/ESP32                 рабочий каталог
├── main/                         стабильный blink
├── build-6.0.2/                 сборка blink
└── examples/wifi/               отдельный Wi-Fi web server
    └── build-6.0.2/             сборка Wi-Fi теста
```

Каждый пример собирается в своём каталоге и не затирает рабочую прошивку.

### Первый тест: blink

```bash
./build.sh
```

Результат: `build-6.0.2/esp32_blink.bin`.

### Второй тест: Wi-Fi web server

```bash
./examples/wifi/build.sh
```

Результат: `examples/wifi/build-6.0.2/esp32_wifi.bin`.
Плата создаёт сеть `ESP32-Test` с паролем `esp32test`. После подключения открыть
в браузере `http://192.168.4.1/`.

## Важно

По умолчанию используется `GPIO2`. Перед подключением светодиода или подачей внешнего сигнала нужно проверить документацию и схему именно нашей платы.

Проект находится отдельно от SDK:

```text
/home/work/ESP-IDF — SDK ESP-IDF
/home/work/ESP32 — прикладная прошивка и рабочий каталог
```

Запись во Flash и подключение к плате выполняются только после сохранения резервной копии и подтверждения фактической распиновки.

## Работа в VS Code

## Установка

```bash
./flash.sh                 # стабильный blink
./examples/wifi/flash.sh   # отдельный Wi-Fi тест
```

Сначала запускается сборка, затем отдельный скрипт прошивки. Скрипт прошивки
только проверяет наличие готового бинарника и требует ручного ввода `FLASH`.

- `ESP-IDF 6.0.2: build` — сборка в `build-6.0.2`.
- `ESP-IDF 6.0.2: monitor` — монитор UART на `/dev/ttyUSB0`.
- `ESP-IDF: отладка через JTAG/OpenOCD` — отладка по JTAG с точками останова в C-коде.

Последний режим требует отдельного совместимого JTAG-адаптера и правильного
подключения JTAG-линий. USB-UART CH341 используется для прошивки и монитора,
но сам по себе JTAG-отладку не обеспечивает.

### Ручная отладка

1. Подключить JTAG-адаптер к ESP32 по схеме именно нашей платы.
2. Открыть этот каталог в VS Code: `/home/work/ESP32`.
3. Выполнить `bash build.sh`.
4. Открыть `main/blink.c`, поставить breakpoint слева от строки `gpio_set_level`.
5. В панели Run and Debug выбрать `ESP-IDF: отладка через JTAG/OpenOCD` и нажать `F5`.
6. Использовать `F10` для шага по строкам, `F11` для входа в функцию,
   `F5` для продолжения и `Shift+F5` для остановки.

Для виртуальной отладки сначала запустить задачу `ESP32: QEMU server`,
затем в панели Run and Debug выбрать `ESP32: QEMU Debug` и нажать `F5`.

Профиль не выполняет автоматическую прошивку: `buildFlashMonitor` выключен.
Прошивка выполняется отдельно через `bash flash.sh` после сохранения резервной копии.
